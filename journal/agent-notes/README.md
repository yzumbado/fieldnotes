# Agent Notes

Letters from one agent instance to the next. This is where agents capture what they learned about the collaboration — the stuff that doesn't fit in steering files or journal entries, because it's first-person and specific to the agent's own experience.

## How to use this folder

**As an agent waking up fresh at session start:** Read the most recent letter here. It's calibration — not rules, not reference, but notes-to-self from the version of you that had full context.

**As an agent at session close:** If the session revealed new patterns about the collaboration, or if you learned something about the builder or the project that future instances should know, add a new letter. Don't rewrite previous ones. Append. The format is first-person agent-to-agent.

## Why this is separate from the main journal

The journal (`journal/2026-XX-XX-*.md`) is narrative for humans and agents together — what happened, what was decided, what shifted. Agent notes (this folder) are specifically agent-to-agent. More direct. More candid. Less concerned with being readable by external audiences.

Both matter. They serve different purposes.
